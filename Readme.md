# forecasting‑modeling‑skill
A LLM system‑prompt skill for time‑series forecasting mathematical modeling, oriented for academic research and industrial algorithm practice.

## Overview
This skill is a set of guardrail rules for large language models, aiming to eliminate common but destructive mistakes in time‑series modeling: look‑ahead bias, data leakage, silent implicit preprocessing, self‑invented algorithms, missing baseline comparison, unreasonable hyper‑parameter tuning, inconsistent mathematical symbols and ad‑hoc terminology.

> Important limitation: This skill **only supports time‑series forecasting tasks**. It contains no constraints for other mathematical optimization problems. It works as guardrails rather than replacing human domain expert review. LLM hallucination may still exist after multi‑turn conversations.

## Core Features
- Standardize full modeling workflow: clarify objectives, explore dataset, explicitly report preprocessing for missing values and outliers.
- Block look‑ahead bias and data leakage for time‑series data splitting.
- Strict hyper‑parameter tuning specification: support fixed independent validation set and walk‑forward validation; prohibit shuffled k‑fold cross‑validation for time‑series.
- Mandatory baseline comparison, with explicit rationale required if baselines are omitted.
- Enforce performance‑complexity trade‑off when iterating models; forbid stacking layers for marginal performance gain.
- Regulate algorithm explanation: consistent mathematical symbols, well‑defined subscripts/superscripts, only adopt established academic & industrial terminology, prohibit self‑coined terms.
